箭头出逃 / Arrows Escape

运行
双击「启动游戏.command」，或者在本目录运行 python3 serve.py。
电脑访问 http://localhost:5174；iPad 连接同一 Wi-Fi，打开启动窗口打印的局域网地址。
发布到 HTTPS 静态托管后，在 Safari 分享菜单中选择「添加到主屏幕」。
不需要 Node 安装、构建步骤或后端服务。

玩法
点选箭头的任意一段，让它沿箭头头部方向移出。
前方有其他箭头会扣一颗心，每关三颗心；全部移出即通关。
提示会高亮一个当前可移出的箭头，不限制次数。
拖动棋盘平移；双指缩放；也可使用 + / − 与「适合屏幕」。
电脑可在棋盘获得焦点后用方向键选择、回车移出；H 提示。
经典闯关提供自由选关和编号跳转，每日一题按北京时间日期固定选关。
闪电挑战从第一次移动开始计时三分钟，切换后台或打开弹窗时暂停。

资源与实现边界
关卡路径来自用户提供的 Arrows – Puzzle Escape 0.24.0 Android 安装包。
包含主线 3983、daily 646、thunderrush 223，共 4852 个关卡布局。
所有布局均已在本实现的碰撞规则下做全量可解性验证。
界面、音效、图标、存档、触控和运行逻辑独立实现。
经典顺序按箭头数量由浅入深重新编排，并非原版关卡顺序。
特殊箭头在本版作为普通箭头处理。元数据存在渐变颜色、选取连锁箭头、连锁间隔等名称，
推测有连锁移除行为，但具体触发规则和数量尚未核实；不能将其称为冻结箭头。
每日选题规则与三分钟挑战时长为本版设定，并非原版运行时行为验证结果。
这是基础玩法复刻，不是 Android 安装包转换，也不是原版 Unity 源码恢复。
原关卡数据的权利归属不变，本仓库不授予原关卡数据的再分发或商业许可。

保存与离线
进度、剩余心数、已移出箭头、设置保存在当前浏览器的 localStorage。
不同浏览器和网址的进度独立；清除网站数据会清除存档。
关卡每 64 个一个包，按需加载，首次只加载第一组。
HTTPS 或 localhost 下 Service Worker 缓存应用及已访问关卡包。
普通局域网 HTTP 地址可游玩，但 iPad 不启用离线 Service Worker。
更改程序或关卡包后应更新 sw.js 中的缓存版本。

文件
app.js：界面、动画、输入、存档、模式切换。
engine.js：路径解码、半格碰撞依赖、提示与路径移动。
data/：已转换的分组关卡。
tools/prepare_levels.py：从 reference/arrows-0.24.0 的提取 JSON 转换并检查可解性。
该脚本只在维护关卡资源时需要，游戏运行不依赖 reference/。

验证
JavaScript 语法检查通过；4852 个关卡、410988 支箭头在实际 JS 引擎下全部可解。
浏览器实际操作验证：消除、通关下一关、提示、碰撞扣心、失败重试、
刷新恢复、拖动不误触、缩放按钮、关卡选择、每日模式和深色设置。
尚未在真实 iPad 硬件上验证双指手势和 Safari 主屏幕安装。
