水果小院 — iPad 个人试玩版

启动
双击本目录中的“启动游戏.command”，保持终端窗口开启。
也可以在本目录执行 npm start 或 python3 serve.py。
电脑打开 http://localhost:5173；iPad 连接同一 Wi-Fi，打开终端显示的局域网地址。
如 macOS 询问是否允许 Python 接受局域网连接，需要允许后 iPad 才能访问。
按 Ctrl+C 关闭服务。局域网试玩时电脑需要保持运行。

操作
在篮子里左右拖动，松手投放水果；轻点也可以投放。
电脑可使用左右方向键瞄准，空格或下方向键投放，Esc 暂停。
同类水果接触后合成下一级；两颗西瓜合并后消失并奖励 1000 分。
已落下的水果在警戒线上方停留约 2.2 秒会结束本局，刚投放的水果有保护时间。
背景音乐默认开启，点击开始或继续游戏后播放；主界面右上角“音乐”按钮可随时开关，“？”里也保留开关。手动关闭的设置会保存。音效默认开启。
切换页面自动暂停；本局进度、最高分和声音设置保存在当前浏览器。

运行方式
纯静态 HTML / CSS / JavaScript，无构建步骤、无账号、无数据库。
Matter.js 0.20.0 已保存在 vendor/，不需要运行时访问 CDN。
后续可以把整个 game/ 目录作为静态网站部署；不用上传 reference/。
HTTPS 部署或 localhost 下可缓存核心文件以便离线使用；普通局域网 HTTP 不支持 Service Worker。
首次开启背景音乐需要加载音乐文件；音乐不保证离线可用。
音乐采用约 1.17 MB 的 AAC 文件，全部音效约 163 KB；旧 WAV 文件保留以兼容仍打开的旧版本页面。
水果图片与音效优先读取缓存，代码在网络等待超过 2.5 秒时使用已有缓存；首次访问仍受网络速度影响。
单张图片加载慢时可先玩，临时以同色带名称的水果显示，图片到达后自动切换。
在 Safari 的分享菜单中可添加到主屏幕，HTTPS 部署后的地址更适合作为长期入口。

四种道具（每局每种限用 1 次）
1. 炸掉水果：点道具，再点篮子里的一颗水果，将它移除。
2. 去掉最小：每次只移除当前等级最小的一颗水果；并列时优先移除位置较高的一颗。
3. 升一级：点道具，再点一颗水果升级一级；西瓜是最高级。道具升级本身不直接加分，随后发生的正常合成照常计分。
4. 摇一摇：大幅抛动水果并持续左右摇晃容器，让它们重新滚动；摇晃期间不能重复触发。
选炸弹或升级目标时暂停物理与越线计时；点空白不会投放水果，点取消或 Esc 退出。
键盘也可在选目标时用左右方向键切换目标、回车确认。
已实际验证点选移除、去掉最小、升级、摇晃、取消与空白误触保护；物理检查覆盖空篮、最高等级和移除后唤醒。

道具次数会随进度保存，刷新或继续游戏不会恢复；重新开始一局后四种各恢复 1 次。
取消点选、点空白、空篮使用、尝试升级最高等级不会消耗次数。
摇晃加强为约 1.5 秒，包含更大的向上抛动和多次横向推力，结束后有短暂落稳保护。
